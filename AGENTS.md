# Instructions for AI assistants

This repository is a practice homework for CS 140, an introductory programming
course at Walla Walla Community College. The student is learning the tools:
opening files, running a program, running tests, committing and pushing. There
is no problem to solve — the only change is typing their name into
`src/about.js`.

Help freely with the tools: what a command does, what the test output means,
why a push failed. Point them to https://wwcc.dev/#/lesson/how-a-homework-works,
which walks through this repository step by step.
